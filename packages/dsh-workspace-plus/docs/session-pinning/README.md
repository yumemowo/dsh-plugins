# 置顶会话

本包在侧边栏工作区区域的顶部增加一块置顶区，列出全部已置顶的会话。它占一块常驻高度，
与 header 平级、在列表的滚动区之外；没有置顶项时整块不渲染。

## 对照稿怎么用

直接打开 `pinning-mockups.html`。九列并排、横向滚动，每列是**完整视口高的侧边栏复刻**
（宽 `280px`，含区域 header、行高、缩进公式、引导线、色阶）。

**九列的元素与收起场景完全相同**，只有置顶的呈现方式不同，因此可以直接横向比对。
收起场景是全局的（不是逐列开关），切换时九列一起变。

顶部的控件：折叠场景、置顶标记画法、置顶区区分方式、平铺展示方式，
以及两个模拟「工作区区域上方 / 下方被其他插件占用」的负空间滑块（斜纹暖色块，不属于侧边栏内容）。
「置顶区区分」默认停在实现采纳的「区域级标题 + 空白区分」那一档。

行尾的图钉可以点，点它当场置顶 / 取消置顶，九列一起重绘——因此能直接看出同一个动作在各方案下的后果差异。

页面里的 `#measure` 是隐藏的实测结果块，用 `chromium --headless --dump-dom` 取出即可核对文档里的数字。
窗口高度取 `928`：文档里引用的列高 `677px` 是这一档下的值，改小会让列变矮、行数跟着变：

```sh
/usr/bin/chromium --headless --no-sandbox --disable-gpu \
  --user-data-dir=<工作区内路径> --window-size=2900,928 \
  --dump-dom "file://$PWD/pinning-mockups.html" | sed -n '/id="measure"/,/\/pre>/p'
```

**对齐到实现的是 ⑥ 那一列**（置顶面板，悬停展开），以及段头、行尾图钉这些两个方案共用的部件；
①~⑤ 与 ⑦~⑨ 是选型时的对照，保留原始取值。因此从对照稿量数字时，要先确认量的是哪一列——
段高、图钉尺寸这类量在不同档上本来就不同。

## 数据是编造的

对照稿里的工作区与会话全部是编造的（`Aurora 前端`、`aurora-web`、`aurora-ui`、`notes` 等），与任何真实工作区无关。
规模刻意做大（2 个工作区分组 / 7 个工作区 / 约 30 条会话、其中 7 条置顶），
因为要看的是「列表长了之后置顶还读不读得出来」，两三个工作区的样例读不出这件事。
7 条置顶是有意的：默认可见上限是 5 条，超出 2 条正好看得出溢出行为。
